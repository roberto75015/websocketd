# docs-archive

Historical planning and audit records, superseded by landed work.
`docsite/` (the real docs site) and its own `STYLE.md`/`PLAN.md` are the
current source of truth, not anything in here.

Nothing in this directory should be trusted as a description of current
websocketd behaviour — it was accurate when written, has since drifted,
and was moved here rather than deleted only to preserve context for
whoever asks "why did we do it that way."

Kept, not deleted, on purpose: quarantine costs nothing; a wrong deletion
is unrecoverable context.
