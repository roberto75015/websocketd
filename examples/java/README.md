## Running the examples on Mac

1. [download and install](https://websocketd.com/docs/start/install/) websocketd and add it to your PATH
2. Echo Server: `cd Echo` then run `websocketd --port=8080 --devconsole ./echo.sh` and go to http://localhost:8080 to interact with it
3. Count Server: `cd Count` then run `websocketd --port=8080 ./count.sh` to start the server, then go to [examples/html](https://github.com/joewalnes/websocketd/tree/main/examples/html) folder and double click **count.html** to open in a browser
